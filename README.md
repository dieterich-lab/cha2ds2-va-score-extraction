# CHA2DS2-VA score extraction

This repository contains supplementary code and documentation for the manuscript
"Evidence-grounded CHA2DS2-VA extraction from German clinical letters using
locally deployable language models". The code extracts the CHA2DS2-VA
stroke-risk score from German CARDIO:DE clinical letters.

The experiments compare a physician-curated rule baseline with Qwen 3.5 9B and
27B models in zero-shot and LoRA-adapted settings. Each model is evaluated both
as a criteria-only extractor and as an evidence-generating extractor that must
return source quotations for the text-derived criteria.

## Study Design

- Dataset: CARDIO:DE400 letters with an expert CHA2DS2-VA annotation layer.
- Validation: letter-level three-fold cross-validation with random seed 42.
- Criteria: `C`, `H`, `A2`, `D`, `S2`, `V`, and `A`.
- Text-derived criteria: `C`, `H`, `D`, `S2`, and `V`.
- Age criteria: `A2` and `A` are calculated programmatically from letter header
  metadata, not generated by the language model.
- Final score: calculated deterministically from predicted criteria.
- Primary metrics: exact score accuracy and micro-average F1 over criteria.
- Evidence metrics: quotation grounding, span-level quotation precision/recall/F1
  against expert annotations, and post-hoc sufficiency/comprehensiveness tests.

CARDIO:DE is available for research use via [heiDATA: 10.11588/data/AFYQDY](https://doi.org/10.11588/data/AFYQDY).
The corpus is split into `CARDIODE400_main` and `CARDIODE100_heldout`; CARDIODE100 annotations are kept in-house. Hence, for reproducible the manuscript reports CARDIODE400 three-fold
cross-validation results. Fixed
CARDIODE400-train/CARDIODE100-test experiments are documented as supplementary
ablations in misc/cardiode/additional_experiments.md.

In our experiments LoRA adaptation improved criteria extraction more
than scaling from 9B to 27B in the criteria-only setting. Evidence generation
reduced score accuracy, especially for 9B models, but enabled source-grounded
review. LoRA also substantially improved strict quotation agreement with expert
evidence spans.

## Reported Results

The following table summarizes the CARDIO:DE400 three-fold cross-validation
results. `C` means criteria-only output and `E` means evidence-generating
output. RMSE is retained here as an additional score-error metric.

| System | Score accuracy C/E | RMSE C/E | Mean criterion accuracy C/E | Micro-F1 C/E |
| --- | --- | --- | --- | --- |
| Rules | 0.440 / - | 1.015 / - | 0.874 / - | 0.852 / - |
| Qwen 9B zero-shot | 0.775 / 0.695 | 0.633 / 0.901 | 0.962 / 0.948 | 0.954 / 0.936 |
| Qwen 27B zero-shot | 0.845 / 0.798 | 0.464 / 0.512 | 0.975 / 0.967 | 0.969 / 0.959 |
| Qwen 9B LoRA | 0.905 / 0.860 | 0.412 / 0.545 | 0.985 / 0.977 | 0.982 / 0.971 |
| Qwen 27B LoRA | 0.903 / 0.895 | 0.406 / 0.415 | 0.985 / 0.983 | 0.981 / 0.979 |

Additional supplementary result tables, including fixed-test ablations,
component-level accuracies, NER ablations, evidence plausibility, and evidence
faithfulness, are available in
[misc/cardiode/additional_results.md](misc/cardiode/additional_results.md).

## Setup

Create a Python environment with GPU PyTorch support, then install the
project requirements:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The Qwen/Unsloth experiments require CUDA hardware (we used CUDA v. 13.3) and local access to
the Hugging Face model weights:

- `Qwen/Qwen3.5-9B`
- `Qwen/Qwen3.5-27B`

The manuscript experiments used one NVIDIA A40 GPU for 9B runs and one NVIDIA
H100 GPU for 27B runs.

## Data Preparation

The notebook `notebooks/data_preparation.ipynb` converts CARDIO:DE UIMA CAS XMI
files and the custom `webanno.custom.CHA2DS2_VA` annotation layer into Hugging
Face datasets. It writes:

```text
data/cardiode_hf_cv3/
|-- cha2ds2_va_train/
`-- cha2ds2_va_CARDIODE400_cv3/
    |-- cha2ds2_va_fold_1/
    |-- cha2ds2_va_fold_2/
    `-- cha2ds2_va_fold_3/
```

Each benchmark script expects the cross-validation data at:

```text
data/cardiode_hf_cv3/cha2ds2_va_CARDIODE400_cv3/
```

The scripts use relative dataset paths -> run each script from its
own directory or update `DATASET_PATH` before execution.

```bash

python 01_physician_rules.py
```

## Implementation Notes

- Decoding is deterministic: `do_sample=False`, fixed seed 42.
- Qwen runs use `MAX_SEQ_LENGTH = 16384`.
- Criteria-only generation uses `MAX_NEW_TOKENS = 160`.
- Evidence generation uses `MAX_NEW_TOKENS = 2048`.
- LoRA runs train one adapter per CV fold with rank 8, alpha 16, dropout 0,
  two epochs, effective batch size 8, and learning rate `1e-4`.
- Evidence spans are anchored back into the source letter by exact,
  whitespace-normalized, and hyphen-normalized matching.
- Evidence span matching uses character IoU with threshold 0.50.
- Faithfulness tests rerun the same frozen model with either only the selected
  evidence spans retained or all occurrences of selected evidence quotations
  removed.
